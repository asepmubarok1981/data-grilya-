# Katalog Battousai

Folder ini sudah disiapkan untuk upload ke GitHub lalu deploy ke Vercel.

## File utama

- `index.html`
- `manifest.json`
- `service-worker.js`
- `icon.svg`

## Cara pakai

1. Buat repository GitHub baru.
2. Upload semua isi folder ini ke repository tersebut.
3. Import repository itu ke Vercel.
4. Deploy tanpa pengaturan tambahan.

## Catatan

- `service-worker.js` dan `manifest.json` dibutuhkan agar PWA bisa di-install di HP.
- Setelah deploy, buka link di Chrome HP lalu pilih `Install app` atau `Tambahkan ke layar utama`.
- File preview lokal seperti `local-preview-server.js` tidak dibutuhkan untuk Vercel, jadi tidak ikut dimasukkan ke folder ini.
